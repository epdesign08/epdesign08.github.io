# EBEN Labs

Tools for people who build things.

This repository holds the EBEN Labs website, served at https://ebenlabs.app. The Jolt and Stallwise repositories appear under the same domain at /Jolt/ and /Stallwise/. It's a plain HTML and CSS page with no build step, served by GitHub Pages.

## Apps

- **Jolt Code**: write MicroPython and HTML on your iPhone and run it on your ESP32 or Pico over Wi-Fi. https://ebenlabs.app/jolt
- **Stallwise**: see what every market, fair and pop-up really earned. https://ebenlabs.app/stallwise
